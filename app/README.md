# A股超跌反转 · 交互式选股器

## 启动
```bash
bash app/start.sh          # 默认端口 8770
bash app/start.sh 9000     # 自定义端口
```
首次启动会加载 1053 万行面板并预计算全部因子，**约 60~90 秒**；之后常驻内存，
每次改参数的重算只需 **0.1~13 秒**。

然后浏览器打开 `http://127.0.0.1:8770/`。

## 默认参数（= 研究报告第 12 节验证的最优 3 条件策略）
| 条件 | 取值 |
|---|---|
| ① 超跌 | 距MA60 处于当日横截面 **D1**（最弱 10%） |
| ② 市值 | **最小 30%**（size_grp ≤ 2） |
| ③ 市场 | 全A等权净值 **< 其 MA60**（熊市） |
| 持有 | **20 日**（T+1 开盘买 → T+21 开盘卖），成本 0.3% 双边 |

实测：CAGR **29.9%** / MDD **−41.3%** / Sharpe **0.98** / 胜率 **58.5%** /
PF **2.19** / 正年份 **10/12** / 四段分期全为正。

## 五个功能页
1. **今日选股** — 列出符合条件的个股 + 关注度打分，可导出 CSV。
   熊市条件会让最新交易日经常无信号，此时自动**回溯**到最近有信号的交易日并提示。
2. **策略回测** — 8 个指标卡 + 分持有期超额表 + 净值/回撤/逐年/四段图 + IS/OOS。
3. **参数寻优** — 勾选维度做网格搜索，按 Sharpe 排序（含负年份数与 OOS）。
4. **单股透视** — 查个股历史信号位置与后续表现（价格/均线/距MA60/量比）。
5. **研究结论** — 全部结论与两个方法学 bug 说明 + 免责声明。

## 自定义股票群（左侧第 ⑥ 组）
- **自定义代码清单**：输入 6 位代码或 `000001.SZ` 形式，逗号/空格分隔；
  可点「载入当前候选」把今日选股结果一键转为股票池。
- **行业筛选**：90 个申万行业，多选。
- **交易所**：沪市 / 深市 / 北交所（北交所流动性弱，默认不选）。

## 预设方案
| ID | 说明 |
|---|---|
| K3 ★ | 距MA60 D1 + 小市值30% + 熊市 — **默认，最优** |
| K2 | 去掉熊市过滤，机会更多但回撤更大 |
| K1 | 仅距MA60 D1（单条件） |
| K12 | 距MA120 D1 + 小市值30% + 熊市 |
| K11 | ret20 D1~3 + 小市值30% + 熊市 |
| D2D6 | 用户原设想：ret20 D2~6（仅供对照验证） |

## 架构
```
app/
├── engine.py        预计算引擎（复用 scripts/v3b_lib.py 的 oret_sig 口径）
├── server.py        本地 HTTP 服务 + 7 个 API
├── index.html       单文件前端（ECharts + 原生 JS，无构建步骤）
├── start.sh         启动脚本
└── README.md
```

## 接口
| 方法 | 路径 | 说明 |
|---|---|---|
| GET | `/api/meta` | 元信息（交易日范围、90 行业、5296 股票清单） |
| GET | `/api/defaults` | 默认参数 + 6 个预设方案 |
| POST | `/api/scan` | 今日选股 |
| POST | `/api/backtest` | 策略回测 |
| POST | `/api/tune` | 参数寻优 |
| GET | `/api/stock?code=` | 单股透视 |
| POST | `/api/export` | 导出候选股 CSV（UTF-8 BOM，Excel 直接打开） |
