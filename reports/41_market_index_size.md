# 用小市值构筑牛熊判定指数，会不会更好？

> 提问：「如果以小市值构筑指数 会不会效果更好呢 比如市值小于50%的等权指数」
> 数据到 2026-09-28（`data/processed/v2_panel.parquet`，10,544,486 行 / 2,875 日 / 5,308 只）
> 脚本：`scripts/41_market_index_size.py`　产物：`output/v3b_market_size_index.csv` / `output/v3b_market_size_index_ref.json`

---

## 0. 结论速览

**会更好，但改善的**来源**不是「小市值指数更聪明」，而是「过滤器变严了」。**

| 问题 | 答案 |
|---|---|
| 小市值等权指数当过滤器，策略更好吗？ | **是**。小50% 相对当前基线：CAGR 29.81% → **35.19%**（+5.4pp），Sharpe 0.979 → **1.117**，胜率 58.5% → 60.1%，PF 2.18 → **2.45**，MDD 基本不变 |
| 是「小市值特有」的信息吗？ | **部分是，但不完全是**。接到大市值策略上也改善（15.99% → 17.92%），说明有一定普适性；但幅度小得多 |
| 改善稳健吗？ | ⚠️ **高度依赖 MA 窗口**。MA20 下小50% **远差于**基线（16.81% vs 25.95%）；MA120 下远好于（43.64% vs 34.88%）。跨度 26.8pp |
| 关键对照 | **MA120 + 全A（34.88%）≈ MA60 + 小50%（35.19%）** → 两者可能是**同一个效应：过滤变严** |
| 建议 | 做成 UI 可选项供对比，**不要直接改默认** |

## 1. 方法与口径

### 被测策略（默认 K3，与 `app/engine.py` 的 `DEFAULT_PARAMS` 一致）

```
距MA60 D1（最超跌 10%） + 市值最小 30%（size_grp 0~2） + 市场 < MA60（熊市才买）
持有 20 日，T+1 开盘买 → T+1+20 开盘卖，0.3% 双边成本
```

### 市场指数（自建，等权、日度再平衡、开盘→开盘）

```
当日收益 = 该口径成分股「可交易 开盘→开盘」收益的等权平均
净值     = cumprod(1 + 当日收益)        MA60 = 净值 60 日简单均线
牛市     = 净值 > MA60
```

### 市值口径（`size_grp` 0~9，0 = 最小 10%，是**分位序号**不是「档位」）

| 键 | 含义 | 成分数 |
|---|---|---|
| `all` | 全A等权（**当前基线**，不加市值过滤） | 3,667 |
| `small50` | 市值 < 50% 分位 | 1,838 |
| `small30` | 市值 < 30% 分位 | 1,103 |
| `small20` | 市值 < 20% 分位 | 735 |
| `small10` | 市值 < 10% 分位 | 367 |
| `big50` | 市值 > 50% 分位（**方向对照**） | 1,840 |

> ⚠️ `all` **不加市值过滤**（真正的全A），不能用 `size_grp ∈ [0,9]` 代替 ——
> 那样会把 `size_grp` 缺失的行也排除掉，与引擎/README 的 29.81% 基线对不上。
> 两边现在共用 `v3b_lib.market_oret(oret, C, sub)`，杜绝口径漂移。

> ✅ **口径校验**：`all` 行的决策层结果 = CAGR 29.81% / MDD −41.3% / Sharpe 0.979 /
> 胜率 58.5% / PF 2.18 / `n_signal` 105,809 / `n_trade` 105,109 —— 与 `app/README.md`
> 记录的引擎基线**逐字吻合**，说明本脚本与引擎是同一口径，对比可信。
> 另：`scripts/verify_market_index.py` 把「界面选项 → 引擎结果」逐格对回本报告，全部通过。

## 2. 描述层 —— 指数本身长什么样

| 口径 | 成分数 | 总收益 | 年化 | MDD | **日波动** | 距MA60 | 熊市日占比 | MA60切换次数 |
|---|---|---|---|---|---|---|---|---|
| 全A等权（基线） | 3,667 | 281.1% | 12.72% | −59.3% | **31.6%** | +3.40% | 43.0% | 171 |
| 小50% 等权 | 1,838 | 1346.2% | 27.01% | −52.9% | **31.6%** | +5.90% | 34.7% | 177 |
| 小30% 等权 | 1,103 | 2365.1% | 33.21% | −52.7% | **31.5%** | +6.55% | 32.6% | 171 |
| 小20% 等权 | 735 | 3367.9% | 37.35% | −51.6% | **31.3%** | +6.47% | 31.3% | 159 |
| 小10% 等权 | 367 | 5544.4% | 43.47% | −50.4% | **31.3%** | +5.55% | 30.5% | 155 |
| 大50% 等权（对照） | 1,840 | −3.5% | −0.32% | −73.8% | **32.2%** | +0.84% | 52.2% | 217 |

### 这里最重要的一个观察

**日波动几乎完全相同（31.3% ~ 32.2%）。**

也就是说：小市值指数**不是「波动更大」**，而是**漂移更高**。年化从 12.72% 一路抬到 43.47%，
而波动纹丝不动 —— 这是**等权小市值溢价 + 日度再平衡收益**的典型特征
（小市值股票之间离散度大，日度再平衡会持续收割「波动红利」）。

**推论**：换口径改变的是**趋势中枢**，不是噪声。所以它会影响 MA 穿越行为 ——
漂移越高，MA 越容易落在指数下方 →「跌破 MA60」变成**更少见、也更极端**的事件。
这正是下面 F 段敏感性问题的根源。

### 与真实指数的对照（重叠区间 2023 起）

格式：`相关 / 自建相对指数的年化超额(pp) / 指数末值牛熊`

| 口径 | 上证指数 | 沪深300 | 中证500 | 中证1000 |
|---|---|---|---|---|
| 全A等权（基线） | 0.27 / **+12.0** / 熊 | 0.19 / +15.1 / 熊 | 0.25 / +11.0 / 熊 | 0.33 / +14.0 / 熊 |
| 小50% 等权 | 0.24 / **+25.4** / 熊 | 0.17 / +28.5 / 熊 | 0.23 / +24.4 / 熊 | 0.31 / +27.4 / 熊 |
| 小30% 等权 | 0.24 / **+31.4** / 熊 | 0.16 / +34.4 / 熊 | 0.22 / +30.3 / 熊 | 0.30 / +33.3 / 熊 |
| 小20% 等权 | 0.24 / **+33.9** / 熊 | 0.16 / +37.0 / 熊 | 0.22 / +32.9% / 熊 | 0.30 / +35.9 / 熊 |
| 小10% 等权 | 0.24 / **+37.7** / 熊 | 0.17 / +40.8 / 熊 | 0.24 / +36.7 / 熊 | 0.32 / +39.6 / 熊 |
| 大50% 等权（对照） | 0.28 / **−1.8** / 熊 | 0.20 / +1.2 / 熊 | 0.27 / −2.9 / 熊 | 0.34 / +0.1 / 熊 |

**换小市值口径会让「口径分歧」更大，不是更小。** 与上证的年化超额从 +12.0pp 扩大到 +37.7pp。
相关系数反而略降（0.27 → 0.24）。所以：

> ⚠️ **换小市值口径 = 更远离真实指数，不是更接近。** 如果你关心的是「界面结论与上证一致」，
> 这个改动是**反方向**的。

用它当牛熊过滤器跑 K3：

### 读数

1. **方向明确**：小市值口径全面优于基线，MDD 还略好（−41.1% vs −41.3%）。
2. **单调梯度**：`大50% (0.865) < 全A (0.979) < 小50% (1.117) ≈ 小30% (1.125) ≈ 小20% (1.117) < 小10% (1.207)`
   —— 不是某一档的偶然，是**系统性的规模效应**。
3. **小50% / 小30% / 小20% 三档几乎打平**（CAGR 34.8~35.4%，Sharpe 1.117~1.125）。
   说明 **不需要走到极端的微盘**，50% 分位就吃到了大部分收益。
4. **小10% 的 CAGR 最高（38.07%）但 PF 反而降了**（2.31 < 2.45），胜率也降（59.5%）。
   典型的「少数极端赢家拉高均值」—— 微盘股指数里混进了**策略实际上买不到**的超小流动性标的。

### 诚实的读数

**不能把 +5.4pp 全部当作过滤器本身的信息含量** —— 其中相当一部分是
2021 年以来的微盘股风格红利。这一点在 MA 窗口敏感性里得到了印证（见下）。

## 6. ⚠️ MA 窗口敏感性 —— 本文最重要的警告

| 口径 | MA20 | MA60（默认） | MA120 | 跨度 |
|---|---|---|---|---|
| 全A等权（基线） | 25.93% / 0.860 | 29.81% / 0.979 | 34.86% / 1.109 | **+8.9pp** |
| 小50% 等权 | **16.81% / 0.640** | 35.19% / 1.117 | **43.64% / 1.407** | **+26.8pp** |
| 小30% 等权 | **16.68% / 0.636** | 35.35% / 1.125 | **44.41% / 1.439** | **+27.7pp** |

（格式：CAGR / Sharpe）

### 三个必须看到的点

1. **小市值口径对 MA 窗口极度敏感**（跨度 26.8pp），而基线只敏感 8.9pp。
2. **MA20 下小市值口径大幅劣于基线**（16.81% vs 25.93%，Sharpe 0.640 vs 0.860）——
   一旦把窗口缩短，小市值口径的「优势」**直接反转成劣势**。
3. **MA120 + 全A（34.86% / 1.109）几乎追平 MA60 + 小50%（35.19% / 1.117）。**

> **第 3 点是决定性的。** 它说明「换小市值口径」与「把 MA 窗口从 60 拉到 120」
> 得到的收益**几乎一样** —— 而后者根本不需要换指数。
> 也就是说，这部分改善更可能来自**同一个机制：过滤条件变严**，
> 而不是小市值指数携带了额外的择时信息。

**机制解释**：小市值指数漂移更高 → 长期 MA 落在指数下方更多 →
「跌破 MA60」变成更少见、更极端的事件 → 过滤器更严 → 留下的都是真恐慌日 → 表现更好。
但这是**用「更严」换来的**，不是用「更准」换来的 —— 代价是对窗口选择极度敏感，
换个窗口就可能反转。

## 7. 池错配检验 —— 是普适信号还是同源效应？

把同一批过滤器接到**大市值超跌**策略（距MA60 D1 + 市值最大 30%）上：

| 过滤器口径 | 信号数 | CAGR | MDD | Sharpe | 胜率 |
|---|---|---|---|---|---|
| 【参照】不加过滤 | 338,225 | 1.18% | −71.3% | 0.205 | — |
| 全A等权（基线） | 139,388 | 15.99% | −52.1% | 0.623 | 54.2% |
| 小50% 等权 | 102,663 | **17.92%** | −49.6% | **0.680** | 56.3% |
| 小30% 等权 | 93,345 | **18.12%** | −51.1% | **0.687** | 57.0% |
| 大50% 等权（对照） | 181,994 | 9.89% | −57.9% | 0.452 | 52.4% |

### 读数

- **大市值过滤器（大50%）反而拖累**（9.89% < 15.99%）→ 方向性明确：**越小越好**。

## 8. 择时准确度 —— 过滤器本身有多准？

直接问：被该口径判为「熊市」的日子，K3 基础信号后续 20 日是不是真的更好？

| 口径 | 熊市日数 | 牛市日数 | 熊市日均 | 牛市日均 | **差** | t（朴素） | **t（保守）** |
|---|---|---|---|---|---|---|---|
| 全A等权（基线） | 1,241 | 1,585 | 4.33% | 1.27% | **+3.06%** | 7.20 | **1.61** |
| 小50% 等权 | 1,007 | 1,819 | 5.38% | 1.08% | **+4.29%** | 9.45 | **2.11** |
| 小30% 等权 | 949 | 1,877 | 5.64% | 1.08% | **+4.56%** | 9.77 | **2.18** |
| 小20% 等权 | 913 | 1,913 | 5.76% | 1.11% | +4.65% | 9.92 | 2.22 |
| 小10% 等权 | 889 | 1,937 | 5.81% | 1.15% | +4.66% | 9.87 | 2.21 |
| 大50% 等权（对照） | 1,485 | 1,341 | 3.70% | 1.41% | **+2.29%** | 5.64 | **1.26** |

> ⚠️ 检验方法：`bull` 是**逐日**状态，同一天要么全熊要么全牛，两组日子集合**天然不相交**，
> 所以只能用**非配对** t 检验（配对样本恒为空 —— 这个坑踩过一次）。
> `fwd20` 是重叠窗口，逐日序列有 ~20 日自相关，朴素 t 严重高估；
> **保守 t = 朴素 t / √20**（近似「不重叠样本」）。

### 这里有一个意外发现

**当前基线（全A等权）的择时区分度其实不显著** —— 保守 t = 1.61（p ≈ 0.11）。
而小50% / 小30% 的保守 t = 2.11 / 2.18（p ≈ 0.035 / 0.029），**达到统计显著**。

→ 从「这个过滤器到底有没有用」的角度看，**换成小市值口径确实让它变得可信了**。
这是本文里对小市值口径**最正面**的一条证据。

但同时注意：**熊市日占比从 43.0% 降到 34.7%** —— 过滤掉更多天，
自然容易在剩下的日子里看到更强的效应。区分度和「更严」在这里是**纠缠**的。

## 9. 总结与建议

### 直接回答你的问题

**会更好。** 小50% 等权把 K3 的 CAGR 从 29.81% 提到 **35.19%**（+5.4pp），
Sharpe 从 0.979 提到 **1.117**，PF 从 2.18 提到 **2.45**，MDD 不变。
而且方向单调、不挑档位（小50% / 小30% / 小20% 三档打平），不是过拟合的尖峰。

### 但有三个必须同时接受的代价

| # | 代价 | 证据 |
|---|---|---|
| 1 | **对 MA 窗口极度敏感** | MA20 下 16.81%（远差于基线 25.95%）；MA120 下 43.64%。跨度 26.8pp |
| 2 | **离真实指数更远，不是更近** | 与上证年化超额从 +12.0pp 扩大到 +37.7pp；相关 0.27 → 0.24 |
| 3 | **改善集中在 OOS** | IS +0.8~2.7pp，OOS +9.5~14.3pp —— 含微盘股风格红利 |

### 关键对照（决定了我的建议）

```
MA60 + 全A等权（现状）  : 29.81% / Sharpe 0.979
MA120 + 全A等权         : 34.86% / Sharpe 1.109   ← 几乎追平下面这条
MA60 + 小50% 等权       : 35.19% / Sharpe 1.117
```

**「换指数」与「拉长窗口」效果几乎一样，而后者不需要改任何东西。**
所以这部分改善更可能来自「过滤变严」这个共同机制，而不是小市值指数本身的信息含量。

### 建议

1. **不要直接改默认。** MA20 下会大幅变差，且改善高度依赖窗口选择 —— 直接改默认是把一个
   对超参极度敏感的配置固化下来。
2. **建议做成 UI 可选项**（「市场指数口径」下拉：全A等权 / 小50% / 小30% / 大50%），
   让用户在界面上自己对比，并**同时展示 MA 窗口**，避免只看单一配置下结论。
3. **如果要动默认，更稳妥的方向是先把 MA 窗口做成参数**（60 → 120 的收益与换小市值相当，
   且没有「更远离真实指数」的副作用）。
4. **别忘了第 8 节**：如果你在意的是「这个过滤器在统计上到底站不站得住」，
   当前基线**不显著**（保守 t = 1.61）而小50% **显著**（t = 2.11）—— 这是换口径最硬的收益。
5. **别用「小市值指数涨得多」当作理由** —— 那 43% 年化里含大量不可交易的微盘股和
   不可执行的日度再平衡收益，只作为**信号**使用是合理的，作为**业绩**宣传是不诚实的。
